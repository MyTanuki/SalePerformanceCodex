# Second Brain: Sale Performance Dashboard

Last updated: 2026-06-15

This folder is the long-form context pack for AI agents working on the Sale Performance Dashboard. It is intentionally split into small files so agents can load only the context needed for a task.

## Reading Order

1. `../../AGENT_CONTEXT.md`
2. `01-business-context.md`
3. The topic file that matches the requested change.
4. `08-agent-handoff.md` before editing or handing off work.

## Documents

- `01-business-context.md`: purpose, audiences, and business vocabulary.
- `02-data-model-and-mapping.md`: input files, key fields, mapping rules, and counting scope.
- `03-revenue-recognition.md`: revenue schedule, recurring target, invoice analysis, and reconciliation principles.
- `04-dashboard-tabs.md`: purpose and meaning of each tab.
- `05-filtering-rules.md`: global filters, tab filters, date fields, and search behavior.
- `06-export-and-reconciliation.md`: CSV export rules and comparison constraints.
- `07-design-decisions-log.md`: important decisions made through the build history.
- `08-agent-handoff.md`: practical checklist for another AI agent.

## What This Is Not

This is not a full chat transcript. It is a curated memory of the business rules, decisions, and working assumptions that matter for future changes.
